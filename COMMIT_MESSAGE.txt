feat: Add comprehensive database migrations for complete 70-table schema

## Summary

Create migrations 012-020 to add 46 missing database tables, bringing total
from 24 to 70 tables. This completes the full enterprise-grade URL shortener
schema including RBAC, teams, billing, CMS, and advanced analytics.

## Problem

- Only 24 of 70 required tables were created on Oracle deployment
- Table definitions scattered across multiple SQL files (database.sql,
  billing_schema.sql, cms_schema.sql, enhanced_analytics_schema.sql)
- SQL files only executed in local development, not production
- initTables() in postgres.go only creates core 24 tables

## Solution

Consolidated all missing table definitions into version-controlled migrations:

### Migration 012: Authentication Extended (empty placeholder)
- Reserved for future auth tables

### Migration 013: RBAC Tables (5 tables)
- oauth_providers, roles, permissions, role_permissions, user_roles
- Default roles: admin, user, premium, team_admin, team_member
- Default permissions for URL, user, team, domain, analytics resources

### Migration 014: Team Management (3 tables)
- teams, team_members, team_invitations
- Support for team-based URL management

### Migration 015: URL Collaboration (9 tables)
- url_shares, url_comments, url_bookmarks, url_favorites
- url_collections, url_collection_items, url_notes, url_activities
- user_activity_logs

### Migration 016: Custom Domains (2 tables)
- custom_domains, domain_analytics
- SSL certificate management, DNS verification

### Migration 017: CMS Tables (8 tables)
- static_pages, page_revisions, page_visits, media_files
- global_settings, content_blocks, page_templates, navigation_menus
- CMS permissions

### Migration 018: Billing Tables (7 tables + functions)
- subscriptions, billing_events, usage_tracking, payment_methods
- coupons, coupon_redemptions, billing_analytics (materialized view)
- Functions: update_usage_tracking, get_current_month_usage,
  create_default_subscription, refresh_billing_analytics
- Trigger: Auto-create free subscription for new users

### Migration 019: Advanced Analytics (14 tables + functions)
- touchpoint_attributions, attribution_model_performance
- realtime_subscriptions, hourly/daily/weekly/monthly_analytics
- country/device/referrer summaries, analytics_aggregation_state
- daily_analytics_summary (materialized view)
- Functions: refresh_daily_analytics_summary, cleanup_old_analytics_data

### Migration 020: URL Mappings Extensions (13 columns + view)
- Add: user_id, team_id, title, description, tags, is_public
- Add: password_hash, custom_domain, utm_* parameters (5 columns)
- Create: urls view (alias for url_mappings)

## Deployment

### Oracle Server:
```bash
git pull origin main
docker exec urlshortener-app /app/scripts/run-migrations.sh
docker exec -it postgresql-central psql -U postgres -d urlshortener_db \
  -c "SELECT COUNT(*) FROM information_schema.tables WHERE table_schema = 'public' AND table_type = 'BASE TABLE';"
# Expected: 69-70 tables
docker-compose -f docker-compose.oracle.yml restart app
```
